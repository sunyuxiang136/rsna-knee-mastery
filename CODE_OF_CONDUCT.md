# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, give and accept constructive feedback, and do not harass or
discriminate against anyone. Maintainers may remove comments, commits or contributions that violate
these standards and may ban repeat offenders.

Report unacceptable behaviour privately to the maintainers through GitHub (Security tab → "Report a
vulnerability", or a direct message to the repository owner).
